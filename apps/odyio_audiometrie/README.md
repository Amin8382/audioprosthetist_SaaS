# Odyio Audiometrie

Audiogramme drawing and analysis module for Odyio audioprothésiste SaaS.

## Features

- Draw audiograms by placing points on a frequency/dB graph
- Left ear (blue circles) and right ear (red crosses)
- Save/load audiogram data per patient
- Standard audiogram grid (125–8000 Hz, -10–120 dB)

## Installation

```bash
bench get-app /path/to/odyio_audiometrie
bench --site odyio.localhost install-app odyio_audiometrie
```
